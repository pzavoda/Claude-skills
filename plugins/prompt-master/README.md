# Prompt Master

Rewrites your rough prompt into a clearer, better-structured one before you send it.

- **Button:** type a rough prompt, then click **✨ Prompt Master** in the band just above the prompt box. The box is replaced with the improved prompt; review it and press Enter. **Undo** puts your original back.
- **Command:** `/prompt-master <rough prompt>` does the same from any surface.

It keeps your intent, names, paths and code, adds the goal, constraints and expected output, and marks anything essential it can't know as `[fill in: ...]`. It uses one Sonnet call per rewrite and never sends anything for you.
